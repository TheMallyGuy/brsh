## Get brsh
Install [LiveContainer](https://github.com/LiveContainer/LiveContainer/releases/latest) via [iloader](https://github.com/nab138/iloader/releases/latest). Then load brsh into Livecontainer using the ipa in the [Releases](https://github.com/TheMallyGuy/living-in-the-bushes/releases/latest)
